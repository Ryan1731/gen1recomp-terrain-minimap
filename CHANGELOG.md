# Changelog

All notable changes to this project are documented in this file.

## [1.0.3] - 2026-08-15

### Added

- Full exterior-footprint colouring for Poké Marts (blue), Pokémon Centers (red), and Gyms (yellow).
- Live markers for nearby uncollected field items: red Poké Balls for ordinary items and yellow Poké Balls for TMs and HMs.
- Compact transparent 8×8 pixel-art marker assets, packaged with the mod.

## [1.0.2] - 2026-08-15

### Changed

- The minimap now anchors to the real display corners on widescreen and other extended viewport sizes, rather than the centred 160×144 UI canvas.

## [1.0.1] - 2026-08-15

### Added

- Configurable minimap opacity: 25%, 50%, 75%, or 100%.

## [1.0.0] - 2026-08-15

### Added

- Live, clean terrain minimap centred on the player.
- Nearby connected-map sampling for outdoor borders.
- In-game visibility, size, and corner settings under OPTIONS → MINIMAP.
